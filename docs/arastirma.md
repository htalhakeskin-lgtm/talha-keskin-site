**Ortak beklentiler (B):** Seçilmiş işler, teknoloji etiketleri, hakkımda, CV indirme, iletişim, GitHub / LinkedIn.
**Boşluklar (fark yaratma fırsatı):** (1) Projeyi siteden çıkmadan **gerçekten kullanmak**; rakiplerde ekran görüntüsü ya da dış bağlantı var. (2) Projenin **düşünce sürecini** (numaralı gereksinim, karar gerekçesi, test sayısı) göstermek. (3) Proje durumunu dürüstçe etiketlemek (Canlı / Demo / Geliştiriliyor).

## 4. İşletme sahibinin iş akışı

- Siteyi yalnızca Talha günceller, ayda birkaç kez, bilgisayardan, kod düzenleyicisiyle.
- Günlük iş yok; yeni proje / deneyim eklemek, CV'yi yenilemek.
- CRM (K7): talep formu yok, e-posta doğrudan gelir → **Sonuç: uygulanmaz.**
